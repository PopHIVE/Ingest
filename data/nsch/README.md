# nsch — National Survey of Children's Health

Single-year, design-based state and national estimates computed from the U.S. Census
Bureau NSCH public-use topical files (2016 onward), sponsored by HRSA MCHB.

- **Raw:** `raw/nsch_{year}_extract.csv.gz` holds only the variables `ingest.R` uses,
  with Census missing-value codes kept as `.M` / `.L` / `.N`. The full Stata zips are
  cached in `raw/zip_cache/` (gitignored) and re-downloaded only when a file's
  Last-Modified / size on www2.census.gov changes.
- **Measure coding:** an R port of the Census/HRSA Title V measure code
  (`Title _V_Code_SAS_2016-2025.sas`); each measure records its Title V variable in
  `measure_info.json`.
- **Estimation:** weights `FWC`, strata `FIPSST x STRATUM`, PSU `HHID`, domain
  estimation, 95% logit CIs. Following the NSCH Comprehensive Analytic Guide, cells with
  an unweighted denominator < 30 are suppressed and CIs wider than 20 points or
  1.2x the estimate are flagged `_unreliable`.
- **Outputs:** `standard/data_age.csv.gz`, `data_age_sex.csv.gz`,
  `data_age_race_ethnicity.csv.gz`. Each measure has `_lcl`, `_ucl`, `_n`,
  `_suppressed`, `_unreliable` and `_not_asked` columns.

Flourishing: `nsch_pct_flourishing_6_17` / `_6mo_5` are "meets all items" (the figure
published by the DRC at childhealthdata.org; reproduced exactly for 2022-23). The
Title V National Outcome Measures (`FlrshChild` / `FlrshYoung`), which judge a child
only on the items answered and run slightly higher, are deliberately not reported.

Most measures are Title V definitions (`title_v_variable` in measure_info). A few are a
single NSCH question reported directly (`nsch_variable`), e.g.
`nsch_pct_share_ideas_well_6_17` (K8Q21 = "Very well" or "Somewhat well"). Adding a variable to
`KEEP_VARS` rebuilds every year's extract automatically on the next run.

`measure_info.json` is generated by `ingest.R` on every run (except `_catalog`, which
is preserved), so edit descriptions in `ingest.R`, not in the JSON. Adding or removing a
measure rebuilds the standard files automatically; to force a rerun for any other
change, clear `raw_state` in `process.json`.
