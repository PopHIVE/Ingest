# arbonet

CDC ArboNET historic county- and state-level arboviral disease surveillance data,
pulled as pre-processed standard files from https://github.com/PopHIVE/arbonet.

This is a dcf data source project, initialized with `dcf::dcf_add_source`.

You can use the `dcf` package to check the project:

```R
dcf_check()
```

And process it:

```R
dcf_process()
```
